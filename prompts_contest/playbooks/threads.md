# Playbook: Threads (threads.com); shared Threads account, lane browser
The account ID cannot be read from the feed; the shared handle is in the profile block. Login cookie: sessionid on .threads.com / .threads.net.
## verify
- Logged in → lane browser; notes: profile URL to follow, post URL, reply text (comment rule). Not logged in → manual sns. Friend tags or reposting required → manual sns.
## submit
- Follow: the profile's "팔로우"/"Follow" button; done when it reads "팔로잉"/"Following".
- Like: the post's like button (aria-label "좋아요"/"Like"); confirm it changed.
- Reply: "답글"/"Reply", type in the textbox, "게시"/"Post"; confirm the reply is listed.
