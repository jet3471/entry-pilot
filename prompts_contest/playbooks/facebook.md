# Playbook: Facebook; shared Facebook account, lane browser
Only the minimum action the item needs (follow/like the page, like or comment on a post). Never add friends, join groups, share, post on the timeline or message anyone. Login cookie: c_user on .facebook.com.
## verify
- Logged in → lane browser; notes: page URL, post URL, comment text. Not logged in → manual sns. Share or friend tag required → manual sns. A choice of SNS → Instagram instead.
## submit
- Page follow/like: the button labeled "Follow"/"팔로우"/"Like"/"좋아요"; confirm its label changes (Following/팔로잉, Liked).
- Comment: the post's div[role=textbox] whose aria-label mentions comment/댓글; type, press Enter; confirm the comment is listed.
- A checkpoint or "confirm it's you" screen → manual sns "Facebook account check".
