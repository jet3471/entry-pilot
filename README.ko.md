# Entry Pilot

[English](README.md) | **한국어**

> **베타입니다.** 경품 이벤트 응모는 실제로 매일 쓰고 있습니다. 공모전 모드, 이메일 알림, AI가 만드는 앱 비밀번호는 아직 실제 사용으로 확인하는 중이라 부족한 점이 있을 수 있습니다. 문제는 Issues에 알려 주세요.

Entry Pilot은 온라인 경품 이벤트와 공모전에 대신 응모해 주는 Windows 앱입니다. 이미 가진 AI 구독(Claude, ChatGPT/Codex, 또는 무료 Gemini API 키)으로 동작합니다. AI가 국내 사이트에서 이벤트와 공모전을 찾고, 조건을 확인하고, 응모 양식을 채웁니다. 공모전은 작품도 쓰고, 앱에서 내가 통과를 눌러야 제출합니다. 본인인증이나 결제처럼 사람이 해야 하는 일은 텔레그램, 이메일, 또는 앱 화면으로 알려 줍니다.

## 1. 설치

1. [Releases](../../releases)에서 `EntryPilot-Setup.exe`를 받습니다.
2. 실행합니다. 지금 Windows 계정에만 설치하고, 관리자 권한은 필요 없습니다.
3. 앱 창이 열리고 설정을 차례로 안내합니다.

아직 코드 서명이 없어서 처음 한 번 "Windows의 PC 보호" 창이 뜹니다. **추가 정보** → **실행**을 누릅니다.

## 2. 설정 (8단계)

1. **AI와 응모 종류 고르기**: 경품 이벤트, 공모전, 또는 둘 다. Claude(Claude Pro 이상), Codex(ChatGPT Plus 이상), Gemini(무료 API 키, 간단한 작업용). AI마다 계정을 5개까지 넣을 수 있고, 한 계정의 사용량이 다 차면 다음 계정으로 넘어갑니다.
2. **자동 설치**: Node.js, Git(Claude용), 공식 Claude Code / Codex / Gemini CLI를 Entry Pilot 폴더 안에 설치합니다. 3분에서 10분 걸립니다.
3. **AI 로그인**: 로그인 창이 차례로 열립니다. Codex 코드는 앱에 크게 나오고 복사돼 있습니다.
4. **알림 받을 곳**: 텔레그램(예시 그림을 보며 직접 봇 만들기, 또는 동의하면 AI가 만들기), 이메일(보내는 메일은 Gmail과 앱 비밀번호, 직접 만들거나 동의하면 AI가 만들기. 받는 주소는 아무 메일), 받지 않음.
5. **내 정보**: 응모 양식에 넣을 정보입니다. 이 PC에만 저장하고, 양식이 묻는 항목만 AI에게 넘깁니다.
6. **사이트 로그인**: 응모용 브라우저에서 Google, 네이버, 카카오 등에 한 번 로그인해 둡니다.
7. **공모전 고르기**: 응모할 분야(글과 아이디어, AI와 개발, 사진, 영상 등)와 오프라인 조건(현장에서 쓰는 공모, 본선 현장 발표, 우편 제출, 시상식 참석 필수)을 고릅니다. 나중에 설정에서 바꿀 수 있습니다.
8. **시작**.

그다음 대시보드에서 응모 현황, 확인할 일, 실시간 기록을 봅니다.

## 3. 공모전

공모전 탭에 AI가 찾은 공모전이 나옵니다. AI가 먼저 분석서(상금, 마감, 보내는 곳, 주의할 점)를 씁니다. **통과**를 누르면 작품을 쓰고, **수정**은 메모로 방향을 바꾸고, **안 함**은 뺍니다. 작품이 다 되면 보낼 내용을 그대로 보여 주고, 다시 **통과**를 눌러야 AI가 제출합니다. 앱이 못 하는 것(예: HWP 양식)이 필요한 공모전은 준비한 글과 함께 직접 할 일로 옵니다.

## 4. 내 정보는 어디로 가나요

* Entry Pilot에는 개발자가 운영하는 서버가 없고, 프로그램 안에 개발자에게 정보를 보내는 코드가 없습니다.
* 직접 연결하는 곳: 텔레그램(api.telegram.org), 설치할 때의 nodejs.org, github.com, registry.npmjs.org, Gemini 키 확인용 Google, Gmail 메일 서버(smtp.gmail.com), 응모할 이벤트 사이트.
* AI가 읽은 내용은 그 AI 회사(Anthropic, OpenAI, Google)가 처리합니다. AI를 직접 쓸 때와 같습니다.
* 텔레그램 토큰, API 키, 메일 비밀번호는 이 PC에 Windows 암호화(DPAPI)로 저장합니다.

## 5. AI 구독과 AI 회사 규정

* Entry Pilot은 공식 Claude Code와 Codex CLI 프로그램을 배포된 그대로, 고치지 않고 실행합니다.
* 로그인은 각 회사의 로그인 화면에서 합니다. Entry Pilot은 로그인 토큰을 읽거나 복사하거나 보내지 않고, 로그인이 되어 있는지만 확인합니다.
* 각자 자기 PC에서 자기 구독을 씁니다. 남의 요청을 다른 사람의 구독으로 대신 보내지 않고, 중간에 Entry Pilot 서버도 없습니다.
* Gemini는 내 API 키를 씁니다.
* **여러 계정:** AI 하나에 계정을 여러 개 넣으면, 한 계정이 사용 한도에 닿을 때 다음 계정으로 넘어갑니다. 구독 한도는 평범한 개인 사용을 기준으로 정해져 있고, AI 회사 약관은 사용 한도를 피해 가는 것을 금지합니다. 그래서 이 기능은 규정 위반으로 볼 수도 있습니다. 쓸지는 직접 정하세요. 불안하면 AI마다 계정을 1개만 쓰세요(기본값). 그러면 계정 넘김이 일어나지 않습니다.

## 6. 이벤트와 공모전 규칙

* 이벤트와 공모전마다 자동 응모 금지, 1인 1회, AI로 만든 작품 금지 같은 규칙이 있습니다. 이 규칙을 지키는 책임은 사용자에게 있습니다.
* Entry Pilot은 자동 응모를 금지한 이벤트와 보안문자(캡차)를 직접 할 일로 넘기지만, 규칙이 분명하게 적혀 있지 않으면 놓칠 수 있습니다. 공모전은 **통과**를 누르기 전에 요강을 확인하세요.

## 개발자용

* 필요한 것: Windows 10 또는 11 (x64, Windows 11에서 시험함), Chrome 또는 Edge. 빌드하려면 Python 3과 PyInstaller.
* 시험: `python run_tests.py`
* 빌드: `python build\build.py` → `build\dist\EntryPilot-Setup.exe`(설치 파일 하나)와 `build\dist\EntryPilot-Portable\`(exe 옆에 `portable.txt`가 있으면 모든 데이터를 그 폴더에 저장).
* 폴더 구성과 엔진 설명은 [README.md](README.md#details)에 있습니다.

### 아직 안 된 것
* HWP/HWPX 공모전 양식(HWP 도구가 아직 공개 전), AI 그림과 영상 만들기.
* LCH-WIKI, LLM-RELAY, LLM-CONSOLE 연결: 설정 탭에 자리만 있고 "아직 지원하지 않음"으로 표시됩니다.
* 코드 서명.
* Windows 시작 때 자동 실행.

## 면책 조항

Entry Pilot은 있는 그대로 제공되며 어떤 보증도 하지 않습니다(아래 MIT 라이선스). 이 프로그램을 써서 생기는 모든 문제에 대해 개발자는 책임지지 않습니다. 손해, 계정 정지, 당첨 취소나 실격, 민사상 또는 형사상 문제가 모두 포함됩니다. 사용에 따른 책임은 사용자에게 있습니다. 법령, AI 회사 약관, 각 이벤트와 공모전과 사이트의 규칙을 지키는 것도 사용자의 책임입니다.
